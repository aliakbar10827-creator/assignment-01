Rules For Naming JS Variables

Variable names can only contains letters with Upper and Lower case. also with numbers, $ , and _ underscore.
For example : $my_1stVariable

Variable must begain with a letters(uppercase , lowercase) , with underscore , and with dolllar($) sign
For Example : $ali , _ali , ali , Ali

Variable names are case sensitive

A variable names should not be JS Key words
For Example : const , let , var , if , etc
